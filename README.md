this is a script to calculate the parameters of a Lorentz curve by fitting a resonance curve. The file with the name "tails" is an extension going from a simple Lorentz curve to a fitting equation considering the neighbouring peaks around the peak of interest. This procedures is explained in the publication added to the repository. 

The folder that contains the MATLAB scripts, should contain a folder with the spectrum file in it.
